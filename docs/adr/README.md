# Architecture Decision Records

Short, dated records of the significant design decisions behind
PostQuantum.Identity and *why* they were made. New ADRs are append-only; if a
decision is reversed, add a new ADR that supersedes the old one rather than
editing history.

| [0003](0003-single-algorithm-suite.md) | Single algorithm suite, no agility | Accepted |
